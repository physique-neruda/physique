Corrigés partagés

Chargement…

Une case cochée ouvre le corrigé sur le site, sans code, à la classe ou à l'élève. Une case décochée le referme — codes compris : le code de la classe et les codes nominatifs de ce corrigé sont refusés, et ce qui avait été débloqué par code se referme à la prochaine visite. « Par code » : aucune décision, les codes marchent comme avant (page « Codes des corrigés »). Entre la classe et l'élève, c'est la dernière décision qui compte. Fermer, c'est faire refuser le corrigé par le site : un code déjà donné ou une clé déjà reçue restent valables pour qui contournerait le site.
