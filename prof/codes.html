Codes des corrigés

Chargement…

Sur le site, chaque corrigé — un exercice, une activité, ou une partie quand l'activité se fait en plusieurs fois — reste fermé jusqu'à ce que l'élève tape son code. Le code de la classe l'ouvre pour toute la classe (à donner en classe ou sur Pronote) ; le code nominatif ne marche qu'avec le compte de l'élève à qui il est donné. Un corrigé débloqué reste ouvert avec le compte de l'élève. Les codes sont recalculés ici avec le code enseignant : rien n'est envoyé, et ils changent à la rentrée (nouvelle année scolaire).

Codes de la classe

Message pour Pronote

Cocher les corrigés à ouvrir : le message donne leurs codes et un lien qui les débloque tous d'un coup (l'élève se connecte, puis le corrigé s'affiche).

Codes nominatifs

Pour un élève seulement (travail rendu, absence…) : son code ne sert à rien à un camarade, et ne donne pas le code de la classe. Il marche dès que la base a reçu les enveloppes de l'année (« comptes_firebase.py cles », outils de comptes v6, à relancer après chaque version du site qui ajoute des corrigés). Cette partie de la page ne s'imprime pas.
