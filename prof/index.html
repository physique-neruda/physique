Tableau de bord L'activité des élèves sur le site, par classe et par élève : élèves actifs, cartes, questionnaires, chapitres travaillés, animations, corrigés débloqués ; avec les mesures d'activité (à activer après l'information des élèves) : temps de travail et questions les plus ratées. Corrigés partagés Cocher ou décocher les corrigés ouverts sans code, pour la classe ou pour un élève ; décocher referme tout, codes compris. Récapitulatif de ce qui est ouvert, fermé ou débloqué par code. Évaluer — U51 par compétences Grilles nationales C2, C13, C17, C18 avec les photos de la classe ; groupes et trinômes, bilan, copie pour le registre Excel, publication des niveaux et de la note aux élèves. Fiches des copies corrigées Après la correction d'un devoir : le fichier de fiches s'importe, chaque fiche s'affiche telle que l'élève la lira (appréciation, points, compétences), puis « Publier aux élèves ». Comportement Registre de la classe : écarts, points positifs et punitions, par élève ou par critère ; journal, bilan, copie pour le classeur. Chiffré sur l'appareil avant tout envoi. Codes des corrigés Pour chaque corrigé d'exercice ou d'activité : le code de la classe, le message à coller dans Pronote (avec le lien qui débloque), et le code nominatif de chaque élève. Le code enseignant suffit.

Ce que voit qui

Chiffré sur cet appareil (illisible pour Google comme pour GitHub) : la liste des élèves avec leurs noms et leurs photos, les lignes de comportement, les saisies d'évaluation (indicateurs, niveaux, commentaires pour le jury). Lisible par l'élève seul, une fois publiés : ses niveaux de compétences et sa note sur 20 pour une épreuve, la fiche de sa copie corrigée (appréciation, points par question, note brute), dans « Mon espace ». Ni nom de famille ni coefficient PAP dans la base. Rien n'est publié sans que vous le demandiez. Mesures d'activité (tableau de bord) : coupées tant que vous ne les activez pas ; lisibles par vous seul.
