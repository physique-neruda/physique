Code de sauvegarde

Pour transporter ton avancement sans compte : copie ce code sur l'ancien appareil, colle-le sur le nouveau. Il contient seulement ton avancement (aucun nom, aucun mot de passe).

Avec le compte donné par le professeur, ton avancement est gardé chez Google (Firebase, serveurs en Europe) sous ton prénom et ton initiale, jusqu'au 31 août ; le professeur peut le consulter. Les documents du site, eux, ne passent jamais par là.
